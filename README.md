# Food Vision - AI Food Classifier

A web application that uses a **deep learning model** to classify food images into **101 categories** from the Food101 dataset. Built with **Flask** and **TensorFlow 2.19**, the app allows users to upload images and instantly see predictions.

---

## Features

- Upload food images directly from the browser.  
- In-memory image processing (no need to save images).  
- Predicts food dish using a **trained TensorFlow model**.  
- Modern, responsive UI using **Bootstrap 5**.  
- Single-page interface: upload and view prediction on the same page.  

---

## Requirements

- Python 3.10  
- TensorFlow 2.19  
- Flask  
- NumPy  
- Pillow  
- Gunicorn (for deployment)
